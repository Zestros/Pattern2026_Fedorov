# Бисквитный торт: рецепт из других рецептов

Учебный пример явной сборки сложного продукта. Торт содержит коржи и крем,
каждый из которых является `recipe_item_model` со своей технологической картой.
Массы полуфабрикатов не задаются готовыми числами: вычисляются по их составу.

```text
Бисквитный торт — 1 штука
├── Бисквитный корж — 3 штуки из партии на 4 штуки
│   └── Карта «Бисквитные коржи»
│       ├── Мука — 200 г
│       ├── Сахар — 150 г
│       └── Яйцо без скорлупы — 250 г
└── Порция крема — 1 штука
    └── Карта «Сметанный крем»
        ├── Сметана — 300 г
        └── Сахар — 100 г
```

## Карта 1. Бисквитные коржи

Выход партии — **4 коржа**. Единица учёта готового коржа — штука.
Масса исходных продуктов задаётся в граммах; яйца учитываются без скорлупы.
Коэффициент выхода после выпекания — **0.9**, учебное допущение.

| Продукт | Количество |
|---|---:|
| Мука пшеничная | 200 г |
| Сахар белый | 150 г |
| Яйцо без скорлупы | 250 г |

По текущим формулам проекта:

- Брутто партии: 200 + 150 + 250 = **600 г**.
- Нетто партии: 600 × 0.9 = **540 г**.
- Масса одного коржа: 540 / 4 = **135 г**.
- В торт идут 3 коржа: 135 × 3 = **405 г**.

Приготовление: взбить яйца с сахаром, вмешать муку, разделить массу
на четыре равные части, выпечь до готовности и остудить.

## Карта 2. Сметанный крем

Выход партии — **1 порция крема** (в справочнике учитывается как одна штука).
Порция означает весь результат приготовления карты, а не фиксированные 400 г.
Коэффициент выхода — **1**; потери при смешивании в примере не учитываются.

| Продукт | Количество |
|---|---:|
| Сметана | 300 г |
| Сахар белый | 100 г |

Брутто и нетто партии по текущим формулам: 300 + 100 = **400 г**.
Приготовление: соединить сметану с сахаром и перемешать до однородности.

## Карта 3. Сборка торта

Выход — **1 торт**. Коэффициент сборки — **1**. Упаковка не используется.

| Полуфабрикат | Количество | Расчёт массы через вложенную карту |
|---|---:|---:|
| Бисквитный корж | 3 шт. | (600 × 0.9) × 3 / 4 = 405 г |
| Порция крема | 1 шт. | (300 + 100) × 1 / 1 = 400 г |

Брутто и нетто торта: **405 + 400 = 805 г**.
Приготовление: прослоить три остывших коржа кремом и собрать торт.
Один корж из выпеченной партии остаётся вне этого торта.

Формулы брутто/нетто здесь соответствуют текущему коду проекта и не меняются
этим примером. В родительскую карту передаётся нетто полуфабриката,
а не исходная масса сырья для его приготовления.

## Создание через явную фабрику

```python
from Src.Models.group_model import group_model
from Src.Models.recipe_item_model import recipe_item_model
from Src.Models.unit_model import unit_model

# В приложении передаём единицы и группу из общего справочника.
group = group_model.create_grocery()
gram = unit_model("грамм")
piece = unit_model.create_piece()

cake = recipe_item_model.create_cake(group, gram, piece)

assert round(cake.calculate_mass(1, gram), 2) == 805
```

`create_cake()` создаёт базовые продукты, вызывает фабрики
`create_sponge_layers()` и `create_sour_cream()`, затем добавляет полученные
продукты в карту сборки. Обе вложенные карты ссылаются на один объект сахара.
Фабрики полуфабрикатов можно вызывать отдельно с продуктами из справочника.
Второй пример создаётся явным вызовом фабрики; первый старт с лепёшками
остаётся прежним. Markdown не разбирается программой.

## Проверка рекурсивного пересчёта

- Если увеличить муку в карте коржей с 200 до 300 г, нетто партии станет
  630 г. Три коржа дадут 472.5 г, весь торт — **872.5 г**.
- Если добавить 20 г какао в исходную карту крема, масса исходного торта
  станет **825 г**. После удаления какао вернётся к **805 г**.
- Если взять два коржа вместо трёх, масса торта станет **670 г**.
- После удаления крема из карты с двумя коржами останется **270 г**.

Сценарии проверяются в `Tst/test_cake_recipe.py`.
