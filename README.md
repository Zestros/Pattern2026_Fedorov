# Ромашка

Система для автоматизации сети ресторанов.

Планируемые возможности:
- Учет продуктов на складах.
- Учет приготовления блюд и полуфабрикатов.
- Управление заказами и доставкой.
- Учет платежей и расчетов с контрагентами.
- Учет сотрудников и графиков работы.

Технологии: Python, SQLite, HTML, JavaScript.

Проект находится на начальном этапе разработки.
